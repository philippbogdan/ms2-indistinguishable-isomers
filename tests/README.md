# Check the choices that can change a verdict

These small checks cover precursor boundaries, matching tolerances, one-to-one assignments, reference maxima, condition eligibility, duplicate flags and conditional repeat agreement. All three displayed spectrum pairs are rescored from their included peaks and compared with the stored unit scores. A corrupted precursor mask must be rejected. Download checks use local bytes.

The standard `unittest` command is in [REPRODUCE.md](../REPRODUCE.md). These checks complement the offline expected-value comparison; full recomputation from the pinned input remains the check of all stored scores.
