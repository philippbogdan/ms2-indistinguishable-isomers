# Start from the public spectra

The complete MassSpecGym input lets you rescore every comparison or change the measurement rule. The pinned TSV is downloaded here; it is too large to bundle. [Download and recomputation commands](../REPRODUCE.md) use the revision, byte length and SHA-256 in [protocol.py](../ms2/protocol.py). Existing files are verified before reuse.

For checking reported numbers or inspecting flagged pairs, the compact [evidence tables](../data/README.md) already contain what you need. They retain [MassSpecGym's MIT notice](../data/MassSpecGym-LICENSE.txt).
